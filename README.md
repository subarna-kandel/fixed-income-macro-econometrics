# Macro-Finance, Fixed Income, and Econometrics

Research examples in bond and yield analysis, macroeconomic time series, data quality, and regression diagnostics.

## Research modules

- Government-bond and Treasury yields, data-quality examples, and equity risk/PCA/SVD.
- Consumption?income stationarity, cointegration, and error-correction analysis.
- Regression sensitivity to outliers and model selection.

## Data and execution

Install dependencies from `requirements.txt` and run from the repository root. Several referenced input files were not present in the supplied material; see `data/README.md`. The macro time-series notebook retrieves FRED data and may require network access.

Review personal information and data-sharing rights before public release.
